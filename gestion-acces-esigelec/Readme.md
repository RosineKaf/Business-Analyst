# 🔐 Gestion des accès – ESIGELEC

## 📌 Contexte
Projet de développement logiciel réalisé à l'**ESIGELEC** (2020-2021), en binôme avec Régis F. Sogbossi.
Pour sécuriser ses locaux, l'école souhaitait une application capable de contrôler les accès selon le **profil de l'utilisateur**, la **zone** et l'**horaire**, à partir des cartes Léo des étudiants et du personnel.

## 🎯 Notre lot : la gestion des accès
- Gérer les personnes et leurs badges (cartes Léo)
- Gérer les lieux : emplacement, horaires d'ouverture, nombre d'accès
- Créer les types d'accès (porte, barrière, parking…) et les associer aux lieux
